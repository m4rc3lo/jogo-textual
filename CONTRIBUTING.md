# Contribuindo

Este é um projeto didático e será construído de forma incremental. Contribuições devem preservar a clareza do material e evitar complexidade que não seja necessária aos objetivos da disciplina.

## Antes de propor uma alteração

Verifique se a mudança:

- mantém o projeto compreensível para estudantes iniciantes;
- possui relação clara com os objetivos didáticos;
- evita dependências e abstrações desnecessárias;
- mantém documentação e implementação coerentes;
- não inclui material interno de avaliação, soluções completas ou informações que não devam ser públicas.

## Organização das alterações

Prefira alterações pequenas e fáceis de revisar. Quando houver código nas etapas posteriores, ele deverá permanecer compilável e acompanhado pelos testes pertinentes.

A documentação será escrita em Markdown e, quando necessário, utilizará Mermaid para diagramas. Scripts auxiliares, caso sejam realmente necessários, serão escritos em Ruby.

## Antes de enviar uma contribuição

Revise os arquivos alterados e confirme que não foram incluídos artefatos locais, dados pessoais, credenciais ou arquivos gerados automaticamente.

As instruções técnicas de compilação, testes e geração da documentação serão ampliadas conforme o projeto evoluir.
